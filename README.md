# Команда AI

Одностраничный HR-чат на React и TypeScript с серверным подключением Gemini. Русский адаптивный интерфейс, быстрые запросы, история в localStorage, подтверждение очистки, индикатор ответа и ошибки. Авторизация и база данных не добавлены.

## Установка и запуск

Требуется Node.js 22.13+.

1. `npm ci`
2. Если `.env` отсутствует, скопируйте `.env.example` в `.env`.
3. Создайте ключ на https://aistudio.google.com/apikey и заполните:

```dotenv
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.5-flash
```

4. `npm run dev`
5. Откройте http://localhost:5173/.

После изменения ключа полностью перезапустите сервер. В текущем проекте ранее введённый ключ Gemini сохранён. Приложение вновь использует только Gemini; Ollama не устанавливался.

Ключ хранится исключительно на сервере. Не присылайте его в чат и не добавляйте в клиентский код. `.env` исключён из Git и архива исходников. Для публикации задайте GEMINI_API_KEY как секрет окружения Sites, при необходимости GEMINI_MODEL, затем опубликуйте сайт. Локальная `.env` не переносится на хостинг.

Без ключа отображается инструкция подключения. При региональном ограничении или превышении квоты показывается пояснение. Локальные запросы исходят с компьютера, на котором работает сервер, а не с телефона. Доступ к API зависит от условий Google и доступной квоты; наличие ключа не гарантирует успешную генерацию.

Документация: https://ai.google.dev/gemini-api/docs/api-key

## Поведение и структура

Enter отправляет, Shift + Enter добавляет строку. Быстрый запрос заполняет поле. История сохраняется в браузере, при загрузке восстанавливаются последние 100 сообщений. Для ответа сервер передаёт Gemini до 30 последних сообщений без ошибок и системную инструкцию. Максимум 8000 символов в вопросе, ожидание ответа до 60 секунд. Сброс требует подтверждения и отменяет запрос.

- `components/chat.tsx` — чат, сообщения, состояния и localStorage.
- `app/api/chat/route.ts` — валидация и запрос к Gemini.
- `lib/chat.ts` — типы, приветствие, системная HR-инструкция.
- `app/globals.css` — дизайн и адаптивность.
- `vite.config.ts`, `lib/dev-env.ts` — локальная среда Node.js; production собирается для Cloudflare Workers.

## Проверка и сборка

`npx tsc --noEmit` проверяет типы; `npm run build` создаёт сборку в dist. `npm start` запускает Worker локально и требует совместимого окружения workerd. Для разработки на Windows используйте `npm run dev`.

В этой среде зависимости установлены через pnpm из-за отсутствия npm; package-lock.json сохранён для стандартной установки. Node.js 24 поддерживает NODE_USE_SYSTEM_CA=1 для системных сертификатов без отключения проверки TLS.

Проверяются TypeScript, сборка и серверная обработка ответов на имитации провайдера. Последний настоящий запрос Gemini до возврата подключения был отклонён Google по региону. После изменения сети необходимо повторить проверку. Браузерные сценарии и необязательный WebMCP stage_hr_question не тестировались.
